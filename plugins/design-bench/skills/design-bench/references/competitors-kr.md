# Competitor Seed — Korea

Curated baseline of Korean apps/sites by category. Used by the design-bench
skill at workflow step 3. Override or extend per project via `.bench/config.yml`.

**Format per entry:**
- `url`: primary domain
- `platforms`: `[web, mobile, desktop]` subset
- `strengths`: one line — what makes this app worth studying
- `screens_of_interest`: which screens are typically the most useful references
- `last_reviewed`: YYYY-MM (helps spot stale entries)

## How to add a new entry

1. Pick the right category (or propose a new one in PR description)
2. Fill all 5 fields (url, platforms, strengths, screens_of_interest, last_reviewed)
3. Keep `strengths` to ONE line — that's the discoverability hook
4. Open PR. Reviewer checks: is the app currently maintained? does it have something
   genuinely worth referencing (not just popular)?
